              Links that open the dashboard with something ready to add. Use them in the Shortcuts app, for Siri (“Hey Siri, log expense”) or Back Tap (tap the back of the phone twice). Nothing is saved until you press Add.

              “Hey Siri, log expense” – 2 minutes

              1. Open the Shortcuts app → + (new shortcut).
              2. Add the action Ask for Input. Type: Text. Prompt: What did you buy? – you'll say or type e.g. “149 rema”.
              3. Add URL and paste the first link above (the one that ends in ?add=). Then tap after it and insert Provided Input from the variables bar.
              4. Add Open URLs.
              5. Rename the shortcut to Log expense. Now say “Hey Siri, log expense”.

              The same works for events (“tor 14 tannlege”), tasks (“betale strøm hver måned”) and workouts (“løp 5 km”) – the line understands all of them. For Back Tap: iPhone Settings → Accessibility → Touch → Back Tap → Double Tap → pick the shortcut.

              Links open in Safari. The first time, unlock there with your passcode; your data is synced, so it's the same as in the app.

              Steps, sleep, heart rate, exercise, weight and more from your iPhone, once a day. A Shortcut sends the numbers to your server; the dashboard picks them up, keeps them encrypted with the rest and deletes them from the server.

              Habits that tick themselves

              How to set it up About 10 minutes, once – Cloudflare first, then your iPhone

              Once, in Cloudflare (3 minutes)

              1. Paste the newest worker.js into the Worker, if you haven't.
              2. Zero Trust → Access → Service auth → Create service token. Name: iPhone Shortcut, duration: non-expiring. Copy the Client ID and Client Secret straight into the Shortcut below – nowhere else.
              3. Access → Applications → your dashboard → Policies → Add a policy. Action: Service Auth. Include: Service Token → iPhone Shortcut. Save.

              The token can only hand in health numbers – it can't read or change anything else.

              On your iPhone (5 minutes)

              1. Shortcuts → +, name it Health to dashboard.
              2. Find Health Samples – Type: Steps, Start Date: is today. Then Calculate Statistics → Sum.
              3. Sleep (summing “Duration” doesn’t work on every iPhone, so each piece of the night is timed from its start to its end):
                1. Adjust Date: Subtract 24 hours from Current Date.
                2. Find Health Samples – Type: Sleep, Start Date: is in the last 1 day, Value is not Awake, is not In Bed, is not Asleep (keeps the Watch’s Core, Deep and REM, so nothing is counted twice). Limit off. No Watch – only In Bed in the Health app? Use one filter instead: Value is In Bed.
                3. Repeat with Each item in Health Samples → If Repeat Item’s Start Date is after Adjusted Date → Get Minutes between Repeat Item’s Start Date and End Date → Otherwise → Number 0 → End If → End Repeat.
                4. Calculate Statistics → Sum of Repeat Results, renamed Sleep sum. That’s minutes – the dashboard turns it into hours.
              4. Get Contents of URL:
                Method POST. Headers: CF-Access-Client-Id and CF-Access-Client-Secret with your two values. Request Body: JSON → Number fields steps and sleep, each set with Select Variable → the blue Sum under its own Calculate action. No date needed – today's is used.
              5. More numbers (optional): one Find Health Samples (Start Date is today) + one Calculate Statistics each, and a Number field with this name. Each gets its own tile, chart and goal.
                exercise Exercise Minutes · Sumactive Active Energy · Sumstand Stand Hours · Sum distance Walking + Running Distance · Sumflights Flights Climbed · Sumdaylight Time in Daylight · Sum hr Heart Rate · Average, todayrhr Resting Heart Rate · Averagehrv Heart Rate Variability · Averagevo2 Cardio Fitness (VO₂ max) · Average, last 30 days weight Weight · Average, last 30 daysmindful Mindful Minutes · Sumwater Water · Sum
              6. Run it once. Open the dashboard – a note says what arrived.
              7. Shortcuts → Automation → + → Time of Day, 22:30, Daily → Run Immediately → Health to dashboard.

              Sleep can come as hours, minutes or seconds – the dashboard works it out. Missing numbers are simply left out.
